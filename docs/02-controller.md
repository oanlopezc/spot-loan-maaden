# 2. Using Spot with the controller

The fastest way to get moving. No computer needed.

## What you have

One controller (tablet) is included in the loan. It talks to the robot over the
robot's own WiFi access point.

## First session, step by step

1. **Insert a charged battery** into the robot. It seats from the top and
   clicks in — see [Charging and batteries](06-charging.md).
2. **Press the power button** on the back of the robot. Wait for the status
   lights to settle; this takes around 30 seconds.
3. **Power on the controller.**
4. **Connect the controller to the robot's WiFi.** The network is broadcast by
   the robot itself. The SSID and WiFi password are on the sheet shared in
   person — *not in this repository*.
5. **Log in** with username `maaden` and the password shared in person.
6. **Locate the E-Stop on screen** before doing anything else.
7. **Press the power/motor button**, then **Stand**.
8. Drive with the sticks. Start slow.
9. When finished: **Sit**, then power down the motors, then the robot.

## Reading the robot

- **Status lights** on the body indicate power and fault states.
- **On-screen warnings** appear on the controller. Don't dismiss and continue
  if you don't understand one — ask us.
- **Battery percentage** is on the controller. Land the robot well before 10%;
  see [Charging](06-charging.md).

## Common first-time snags

| symptom | likely cause |
|---|---|
| Controller won't connect | Robot not fully booted — wait, then retry |
| Login rejected | Username is `maaden`, all lowercase |
| Robot won't stand | E-Stop is engaged, or motor power is off |
| "Behavior fault" | Robot hit its limits — sit, then stand again to clear |
| Walks then stops repeatedly | Obstacle avoidance reacting; check surroundings |
