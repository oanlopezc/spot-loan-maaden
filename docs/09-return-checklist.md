# 9. Return checklist

Planned return: **Tuesday 25 August 2026**. If you need longer, tell us before
that date — an extension is not a problem, only a surprise is. We're planning
our own work around the robot's availability, so an approximate date helps.

Run through this the day before, not on the morning.

## Hardware

- [ ] Payload reassembled as delivered — VLP-16, Spot CORE, Spot GXP on the 4× rail mounts
- [ ] Any of your own hardware removed
- [ ] **Both batteries charged**
- [ ] Charger and all three cables in the case — power, Spot charging, battery charging
- [ ] Controller included and charged
- [ ] Robot wiped down if it's been outdoors

## Software

- [ ] Firmware on the delivered versions, or discussed with us beforehand — see [Versions](07-versions.md)
- [ ] WiFi SSID, WiFi password, and IP configuration unchanged
- [ ] Your data copied off — we may reimage, so don't leave your only copy on the robot

Please leave the `maaden` account in place. We'll remove it ourselves after the
return.

## Tell us about

- [ ] Anything that broke, jammed, or behaved oddly — **even if it seems minor now**
- [ ] Any falls or impacts
- [ ] Batteries that seem degraded
- [ ] Anything in this documentation that was wrong or missing

There's no penalty attached to any of this. We'd far rather know about a
hairline crack than discover it three weeks later.

## And if you're willing

How the Emesent integration went — what worked, what fought you. We're likely
to attempt something similar and would rather learn from you than repeat it.
